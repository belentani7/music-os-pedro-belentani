Compón con estructura.

Parte de un tema, idioma, tempo y tonalidad. Los agentes de composición y producción desarrollan el material dentro de un mismo proyecto MusicIR. Revisa el resultado y conserva el control creativo: la respuesta de un modelo no sustituye tu criterio.

Un flujo que puedes inspeccionar.

  1. 01

    Definir. Tema, influencias, idioma, BPM, tonalidad y creatividad.

  2. 02

    Desarrollar. Letras, acordes, instrumentación, dinámica y espacio dentro del proyecto.

  3. 03

    Exportar. Guarda JSON y MIDI para continuar en tu entorno musical.

La aplicación vive en tu equipo.

Necesita Python, las dependencias del repositorio y Ollama ejecutándose localmente. La siguiente configuración reproduce el ejemplo del proyecto.

git clone https://github.com/belentani7/music-os-pedro-belentani.git
cd music-os-pedro-belentani
python -m venv .venv
# activa .venv antes de continuar
python -m pip install -r requirements.txt
ollama pull qwen2.5:7b
streamlit run project/music_os_ui.py

El modelo se descarga en tu equipo y necesita memoria y almacenamiento disponibles. Si Ollama falla, la aplicación informa del error.

Instrucciones para Windows y Linux

Lo que entrega y lo que exige.

El MIDI representa progresiones y arreglos. No es un master de audio, una mezcla terminada ni una canción cantada. Esta web presenta el proyecto; no ejecuta Ollama ni genera canciones online.

El historial se guarda en music_os_history.json en tu equipo. Revísalo antes de compartir una carpeta. La demo es simulada y las puntuaciones de originalidad son estimaciones del modelo, sin validación externa.

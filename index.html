Compón con estructura.

Los agentes de composición y producción trabajan sobre un mismo proyecto MusicIR: secciones, acordes, letra, instrumentación, dinámica y espacio. Antes de descargar, lo ves: un piano-roll dibujado a partir del propio archivo MIDI. El modelo propone; tú decides.

Un flujo que puedes inspeccionar.

  1. 01

    Definir. Tema, estilos, idioma, BPM, tonalidad y creatividad.

  2. 02

    Desarrollar. Letra y acordes por sección, con dirección vocal e instrumentación declarada.

  3. 03

    Escuchar el boceto. Maqueta MIDI a tres pistas con tres grooves: arpegio, pad y stabs.

  4. 04

    Exportar. MIDI para el DAW, hoja de sesión en texto y el proyecto completo en JSON.

La aplicación vive en tu equipo.

Necesita Python y las dependencias del repositorio. Para generar con un modelo real, Ollama ejecutándose en local. Si no lo tienes, el modo demo permite recorrer toda la interfaz con un proyecto de ejemplo, siempre etiquetado como simulación.

git clone https://github.com/belentani7/music-os-pedro-belentani.git
cd music-os-pedro-belentani
python -m venv .venv
# activa .venv antes de continuar
python -m pip install -r requirements.txt
streamlit run project/music_os_ui.py

Con modelo real, además: ollama pull qwen2.5:7b y Ollama en marcha. Sin modelo, activa «Usar modo demo» en la barra lateral.

También hay CLI: python -m tools.music_os_cli generate --theme "tu idea" --demo

Lo que entrega y lo que exige.

El MIDI representa progresiones y arreglos: no es un máster de audio, ni una mezcla terminada, ni una canción cantada. Esta web presenta el proyecto; no ejecuta Ollama ni genera canciones online.

El historial se guarda en music_os_history.json en tu equipo. Revísalo antes de compartir una carpeta. La demo es simulada y las puntuaciones de originalidad son estimaciones del modelo, sin validación externa.

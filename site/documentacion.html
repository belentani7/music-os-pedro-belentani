Documentación de MUSIC OS

Instalar, generar, exportar y verificar. Todo lo de esta página se ejecuta en tu equipo.

1 · Instalación

git clone https://github.com/belentani7/music-os-pedro-belentani.git
cd music-os-pedro-belentani
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt

Python 3.10 o superior. El núcleo y la CLI solo necesitan midiutil y ollama; Streamlit, pandas y plotly son para la interfaz.

2 · Interfaz

streamlit run project/music_os_ui.py
  • Modo demo: activa «Usar modo demo» en la barra lateral. No llama a ningún modelo; el proyecto es un ejemplo fijo del código y aparece marcado como simulación.
  • Modelo real: con Ollama en marcha (ollama serve) y el modelo descargado (ollama pull qwen2.5:7b). Si el modelo falla, la app lo dice y no sustituye el resultado por la demo.

3 · CLI

python -m tools.music_os_cli --help
python -m tools.music_os_cli generate --theme "alienación digital" --demo --out salida/
python -m tools.music_os_cli verify salida/Eclipse_en_la_Ciudad.mid
python -m tools.music_os_cli inspect salida/Eclipse_en_la_Ciudad.musicir.json
python -m tools.music_os_cli history --limit 5

generate escribe cuatro archivos: el proyecto .musicir.json, la maqueta .mid, la hoja de sesión .txt y un piano-roll .svg generado a partir del propio MIDI.

4 · MusicIR

Un único objeto describe la canción: metadata, concept, musical, lyrics, harmony, melody, arrangement, production, evaluation y memory. MusicIR.from_json migra documentos antiguos y validate() comprueba BPM, compás, tonalidad, secciones, acordes y letra.

  • Los documentos sin schema_version se migran al esquema 2.0.
  • Los acordes se interpretan con project/music_theory.py (una sola fuente de verdad).
  • Un IR inválido no se exporta: la exportación falla con el motivo.

5 · MIDI

ElementoDetalle
FormatoSMF tipo 1, varias pistas
Pista 0Tempo, compás y armadura
Pista 1Armonía (GM 5, piano eléctrico)
Pista 2Bajo (GM 39, synth bass)
Groovesauto, arpeggio, pad, stab

El MIDI es un boceto de arreglo: no contiene audio, ni voz, ni mezcla. Para convertirlo en sonido necesitas un DAW o un sintetizador.

6 · Verificación

python -m unittest discover -s tests -p "test_*.py" -v
python -m compileall -q .
ruff check .

Las pruebas cubren el ciclo demo, la exportación MIDI (cabecera, pistas, grooves distintos, lectura de vuelta), la recuperación del historial corrupto, la migración de MusicIR, el fallo de proveedor y el contrato de publicación del sitio.

7 · Privacidad

Nada sale de tu equipo salvo que tú lo envíes. Ollama responde en localhost. El historial es un archivo local: bórralo desde la app o con python -m tools.music_os_cli clear-history. Ver Privacidad y datos.

Arquitectura del Agente Compositor Musical Universal
Este documento detalla la arquitectura de un agente de inteligencia artificial diseñado para componer canciones de manera autónoma y personalizada, integrando principios artísticos y técnicos de diversos géneros y artistas. El objetivo es crear un sistema capaz de generar letras y melodías con un criterio real, adaptándose a diferentes idiomas y estilos musicales, y funcionando de manera robusta en entornos locales.
1. Principios Fundamentales del Diseño
El agente se construye sobre los siguientes pilares, extraídos del análisis de las conversaciones previas [1]:
Pensamiento Nativo del Lenguaje: La composición de letras se realiza directamente en el idioma objetivo, sin procesos de traducción intermedios, para preservar la tonalidad, sonoridad y prosodia intrínseca de cada lengua. Esto asegura que las letras no solo sean gramaticalmente correctas, sino que también resuenen cultural y fonéticamente con el idioma.
Teoría Musical Avanzada: El agente incorpora un profundo conocimiento de armonía tonal y modal, acordes extendidos y alterados, polirritmias y construcción melódica compleja. Esto permite generar estructuras musicales ricas y sofisticadas, más allá de las progresiones básicas.
Síntesis Artística Personalizable: La capacidad de fusionar las características distintivas de múltiples artistas (como la teatralidad de Lady Gaga, la melancolía de The Smiths, el groove de Anitta y la tensión armónica de Nathy Peluso) permite al agente crear un perfil artístico único y adaptable a las preferencias del usuario (ej. Pedro Belentani).
Robustez y Tolerancia a Fallos: El sistema está diseñado para anticipar y manejar errores comunes en la interacción con modelos de lenguaje grandes (LLMs), como la salida de JSON malformado o la generación de acordes inexistentes, garantizando la continuidad y fiabilidad del proceso de composición.
Independencia y Ejecución Local: El agente está concebido para operar en un entorno local (Windows, Mac, Linux) utilizando modelos de lenguaje de código abierto (como Qwen o Llama) a través de Ollama, lo que le confiere autonomía y elimina la dependencia de servicios en la nube o conexiones a internet constantes para la composición.

Este módulo es el cerebro del agente, encargado de interactuar con el modelo de lenguaje grande (LLM) para generar el contenido textual y estructural de la canción. Sus componentes clave son:
Generador de Prompts Dinámico: Construye prompts complejos y detallados que instruyen al LLM sobre el idioma, tema, BPM, tonalidad y los estilos artísticos a fusionar. Incluye directivas fonéticas específicas para cada idioma y exige una estructura de salida JSON predefinida.
